使用说明

  1. 先装好：打开扩展管理页（Chrome：chrome://extensions/；Edge：edge://extensions/）→ 打开「开发人员模式」→「加载解压缩的扩展」→ 选择 extension 文件夹 → 固定到工具栏。
  2. 采普惠价：在浏览器里登录普通/普惠电商平台账号 → 点扩展图标打开工作台 → 点「普惠号巡检」。默认每批 40 个、间隔 3–6 秒，可随时暂停/继续/停止。
  3. 采会员价：退出账号，登录 PLUS 会员账号 → 再点「会员号巡检」。两列价格会并排显示。
  4. 总览页：点顶部「总览」可看整体进度、各状态数量；点数字筛选查看对应行；表格同样可以手动改价。
  5. 同品比价：点顶部「同品比价」，会按「套餐型号」自动把不同店铺（3C店铺 / 大家电）里的同款产品配成一组（忽略空格、-京仓、大小写），并排对比两边采集到的普惠价 / 会员价；有价差的组会排在最前面并标红，可只看差异、导出比价 CSV。只有未下架且两边都是同一型号的行才会配对。页面顶部还有「采集全部比价 SKU」按钮：一键把这 30 个比价 SKU 用同一个账号、同一条轨道重新采一遍，采集完自动刷新对比。
  6. 汇总上报：在总览勾选要上报的行 → 「汇总选中」→ 行变浅红底色进入「待上报区」→ 「导出待上报 Excel」。
  7. 成交价校验：只记录页面读数与阈值的偏离，不会自动"挑一个接近阈值的值"；差价超过 500 元只提示，超过 1500 元标「需人工确认」。核对无误点价格旁的「确认」→ 状态变「正常」；如需改价点「改」。
  8. 确认 / 改价 / 重采：带「需人工确认」的价格点「确认」→ 状态转「正常」；点「改」手动修正；重采时（单行「重采」或勾选后「重采选中」）会弹窗让你选账号（普惠/会员）和轨道（后台标签页/前台窗口+AI），可以记住默认选择。
  9. 小眼睛预览：表格右侧「预览」列的眼睛，鼠标悬停会弹出商品页小窗，移开自动关闭；点一下可固定窗口，再点关闭。悬停多久弹出可在「设置 → 预览悬停延迟」里调整（默认 1000 毫秒）。
  10. 下架库：确认商品已下架，点「下架」移入下架库（默认隐藏、下次巡检不再出现；按 SKU 记录，重新导入基表也保留）；在状态筛选「已下架」里可点「恢复」放回来。
  11. 没有 SKU 的行：在表格里直接补（纯数字，自动保存）；也可以补进 Excel 后重新生成基表。
  12. 管理基表：工具栏「管理基表」可直接增删改 SKU、套餐型号、前台价、阈值和类目；可先「导出基表 JSON」备份，改完点「保存修改」立即生效；需要还原就点「恢复内置」。
  13. 导入 Excel 基表：工具栏「导入基表」可以直接选 .xlsx 巡检表（表头要有 sku、套餐型号；列顺序随意；sheet 名=类目），导入时自动按 SKU 去重、重复 SKU 保留最后一条数据；如果阈值写成简单公式（如 =E58-1060）也会自动算出来；导入前会显示「与当前基表对比：新增 SKU / 普惠阈值 / 会员阈值 / 前台价 各多少处变化」。
  14. 轨道切换：运行条最左边「轨道① 后台标签页 / 轨道② 前台窗口+AI / 矩阵③ 阵列速采」可随时切换；三条轨道用的是同一套取价脚本，差别只在打开方式（后台标签页 / 前台小窗 / 并行阵列）和是否跑 AI 复核。
  15. 矩阵速采（新版）：点「⚡ 矩阵速采 · 普惠」或「· 会员」，默认直接打开多个真实商品页窗口，按屏幕宽度沿弧线排开（默认每批 6 个、错开 300ms），整批读完后只写一次存储，然后页面淡出、窗口逐个关闭，再开下一批。真实窗口本身无法碎裂，只能淡出；想保留「碎成粉末」动画，可在设置里把「矩阵打开方式」改成「后台标签页 + 矩阵大屏」，或点状态栏「▣ 矩阵大屏」打开可选 HUD。
  16. 矩阵参数：设置 →「矩阵速采参数」可切换真实多窗口 / 后台标签页+大屏，并调整每批并发数（2–12，真实窗口建议 4–6）、开页错开毫秒、批次间隔和粉末动画开关。并发越高越快，但越容易触发风控；看到「安全验证」请立即调小或停止。
  17. AI 已预配置：AI 接口、模型、Key 都已写好（数据在本机）；AI 只做校验/兜底，不覆盖 DOM 读数，截图只在内存里用完即删、不保存。
  18. 官方API：API 桥开机自启（Windows 计划任务，与双轨版共用 127.0.0.1:18765），点「官方API采集（普惠）」即可。账号凭据可在「设置 → 官方API账号」里按供应商直接填写 appKey / appSecret / accessToken，点「保存并测试」会用基表里的 SKU 试读一次；token 失效会报「access_token 无效」，重新粘贴新 token 即可，不用改文件。
  19. 取价不准：设置 →「复制调试 JSON」，发给我按页面结构调整识别规则。

数据只存在本机浏览器（chrome.storage.local），不上传服务器。请低频、分批使用，不要做无人值守高频抓取；看到安全验证就停止。
