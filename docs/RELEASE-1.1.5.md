## 二、v1.1.0 这一版做了什么（同日早些时候）

1. **价格巡检业务整包升级到 v1.3.4 完整版**（替换 v1.2.2）：
   - 内置基表 **153 行 / 146 行有 SKU**（合并「大家电新表」、更新 58 处会员最低到手价）；
   - 新增**内置基表自动升级**（`generatedAt` 更新时自动替换，已下架/手动改价按行号+SKU 保留）与差异提示；
   - 官方 API 采集支持**多个供应商账号**（设置页可增删/保存/测试，需配套新版 `api_bridge.py`）；
   - 清空采集前自动下载 JSON 备份；
   - 其余（双轨采集、普惠/PLUS、同品比价、导出/回填）保持并已回归。
2. **三个业务的取价逻辑统一到巡检基准**：
   - 用 15 个 mock 商品页场景（标准/PLUS/跨平台比价干扰/关联购买推荐/隐藏价/拆分数字/折扣片段/下架/售罄/验证页/首屏外/小字划线/券后价/二次刷新/无到手价标签）对比三套 `content.js`；
   - 修复市占率 4 处、竞品 1 处；巡检（**仅平台副本**）2 处取价边界（拆分小数拼接 `￥8,607+.56 → 8607.56`、电商平台价优先带标签/划线候选，避免把优惠券金额当电商平台价）；
   - 最终 15 个场景三引擎逐字段一致（到手价/电商平台价/PLUS 价/页面状态）。
3. **修复竞品监控两个真实 bug**：
   - `saveMeta()` 写后校验用 `JSON.stringify` 比较对象，chrome.storage 读回时键顺序被重排 → 永远误报「写入校验不一致」并抛错，
     导致保存基准价/备注/标记下架/导入备份全部失败（high）；已改为稳定序列化比较；
   - `storage.onChanged` 同样问题 → 自己保存也会误弹「已同步其他工作台标签页的数据」；已同法修复。
4. **原始三个插件目录未做任何修改**：巡检 v1.3.4 的 zip / 桌面原插件都没动，以上改动只落在平台 `modules/` 副本里；
   平台内巡检副本比原始 zip 多 2 处取价边界修复，若你想让原插件也同步，需要把这 2 处 patch 回原目录。

## 三、怎么装、怎么用（和上一版一致）

1. Edge 打开 `edge://extensions/` → 开启「开发人员模式」→「加载解压缩的扩展」→ 选择 `价格监控平台` 文件夹（含 `manifest.json` 那一层）；
2. 点工具栏图标 → **先选择业务**（价格巡检 / 市场占有率 / 竞品监控）→ 进入后界面与原插件一致；
3. 顶部细条：切换业务 / 业务选择（Esc 回首页）/ 独立打开；支持数字键 1/2/3、深链 `#/patrol`、刷新保持当前业务；
4. 长任务（几十上百个 SKU）请点右上角「**独立打开**」在独立标签页里跑——平台内切业务会卸载当前业务页面，正在跑的采集会中断。

### 升级方式与数据保留

- **同路径覆盖安装**（把新版文件覆盖回原来的 `价格监控平台` 目录，再到 edge://extensions 点「重新加载」）：
  扩展 ID 不变，**本机数据（chrome.storage）会保留**；巡检基表会按 `generatedAt` 自动升级到 153 行版本并保留已下架/手动改价状态。
- **换到新路径**（例如从 `三合一\价格监控平台` 换到 `软件成果\价格监控平台`）：扩展 ID 会变 = 新存储，需要用各业务的「导出 JSON」→「导入备份/导入数据」迁移；
- 从旧的三个独立插件迁移：仍按旧办法导出/导入（见第五节）。

## 六、已知限制 / 未覆盖（诚实说明）

- **真实电商平台商品页未联网验证**：三业务取价矩阵、content.js 共存、竞品 mock 采集用的都是 CDP 拦截返回的本地 mock 商品页；
  真实登录态、电商平台券计算、A/B 改版差异仍建议先小批量（3~10 个 SKU）真机试跑一轮。
- **AI 复核的外网调用没触发**（避免真实 Key 请求）；官方 API 桥只验证了「已连接/多账号列表/未连接降级」，
  没做真实 SKU 的采价联调。
- **真实批量采集未执行**（需登录电商平台账号、会真实打开商品页），只验证了运行入口确认弹窗、取消路径、单条 mock 采集成功/下架失败链路。
- 未覆盖真实多标签页并发采集、双击/重复点击、升级重装后的极端迁移边界。
- 巡检 v1.3.4 产品本身没有「表格排序/分页/SKU 抽屉」，深度验收记为 3 项 SKIP（不是功能缺失）。
- 平台内巡检副本含 2 处取价边界修复（见第一节第 2 条），与桌面原插件行为存在这两处差异。
