采集是怎么跑的

  1. 只读页面：逐个打开电商平台商品页，只读 DOM 里的价格，不点击、不提交订单、不调用电商平台接口。
  2. 锁价格区：只在商品主价格区（product-price / summary-price 等）取「到手价」，自动排除跨平台比价卡片、关联购买、推荐和广告位。
  3. 不猜价：读数不稳定就继续等；页面没价、风控验证、商品下架都如实记录，不会拿相近的数字凑一个结果。
  4. 低频：默认每个 SKU 间隔 3–6 秒，可暂停/停止；连续失败会自动暂停。看到安全验证请立即停止。

使用说明

一分钟上手

  1. Edge 打开 edge://extensions/ → 打开「开发人员模式」→「加载解压缩的扩展」→ 选择 竞品价格雷达\extension → 固定到工具栏。
  2. 点扩展图标打开工作台。内置监控清单来自《线上竞争数据分析（月度）.xlsx》，共 176 个竞品 SKU。
  3. 先登录电商平台账号，在「监控清单」里选范围（当前筛选 / 全部），点「开始采集」。默认后台标签页逐个采，不弹窗，可继续用电脑。
  4. 采完看「总览」：今日异动、降价/涨价、价格变动榜。点任意行看价格走势和采集记录。
  5. 写入今日记录（日期记录表）：采集完点「写入今日记录」，会把本批所有成功采集到的最新价一次性批量写入今天这一列（不需要一个个 SKU 手填）；每次确认新增一天记录，下一轮采集的「较基准」百分比以每行最近日期列的价格为基础。点「记录表」按钮可查看「日期 × SKU」矩阵、导出 CSV、清空。
  6. 导出最新数据：「监控清单」右上角有「导出最新数据」，把当前筛选结果导成 CSV（Excel 可直接打开），行顺序按基表原始顺序排列（序号=基表行号），含基准价、最新价、采集时间、较基准%、状态、标签、备注和商品链接。
  7. 异动阈值在「设置 → 异动预警」里调；采集间隔默认 3–6 秒；每次最多可先设 10 个试用。

取价规则（重点）

  • 锁主价格区：只在商品价格区里找「到手价」（旧版 product-price / summary-price / #price，2026 新版 page-right-price / product-price--main 等），不再全页扫价。
  • 排除诱饵：跨平台比价卡片、关联购买/常购、推荐/广告/榜单/足迹等模块里的「到手价」全部拉黑。
  • 只认可见：隐藏元素、屏幕外、零尺寸的候选一律跳过。
  • 拼接数字：¥8,607 + .56 会拼成 8607.56，拒绝 56、.56、5折、满5000减500 这类片段。
  • 等定格：连续 3 次读数一致才算稳定，之后还会复核页面二次刷新的最终价。
  • 不猜价：取不到就记失败/待核对，不会拿一个"看着合理"的价格凑数。

数据与安全

  • 采集只读页面 DOM，不点击、不提交订单、不调用电商平台接口。
  • 所有数据只保存在本机 chrome.storage.local，不上传服务器；截图不保存。
  • 低频使用（3–6 秒/个），分批、可暂停；看到「安全验证」立即停止，休息一段时间再试。
  • 在 edge://extensions/ 里「移除」扩展会清空本地数据；更新代码只点「重新加载」，换路径前先导出备份。

常见问题

  • 价格读错？设置 → 调试 →「复制最近一次取价 JSON」，里面包含候选价格、字号、位置，便于按页面结构调整规则。
  • 一直超时？确认已登录、能正常打开电商平台商品页；把每批数量调小、间隔加大再试。
  • 页面改版？把调试 JSON 保留下来，调整 content.js 里的主价格区选择器或排除规则即可。
  • 想换清单？改工作区 Excel 后运行 python tools/build_watchlist.py 重新生成 data/competitor-skus.json。
